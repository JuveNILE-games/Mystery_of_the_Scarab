# JuveNILE Games — Logo Reveal

Studio splash animation for the games, built with [Remotion](https://www.remotion.dev).
~4 seconds, 1920×1080 @ 60 fps.

1. **Magnetic halves**: two plain scarab shell halves hover apart, tilted open like wing cases.
   An inverse-square attraction (`src/magnet.ts`) pulls them in: barely moving at first, then
   accelerating ever harder. Field lines arc across the gap and energy motes stream into the seam.
2. **Snap → controller**: the halves slam together (flash, ring, camera jolt). The d-pad and
   then each button punch open with light shining through, and the scarab becomes the controller.
3. **Legs** spring out pair by pair and scuttle.
4. The beetle glides into its place in the lockup while **JUVENILE GAMES** rises out of the sand.
5. A gold glint sweeps across the logo, it holds, then fades out.

## Output

| Composition             | File                                   | Use                                                   |
| ----------------------- | -------------------------------------- | ----------------------------------------------------- |
| `LogoReveal`            | `out/JuveNILE_LogoReveal.mp4`          | Full-screen splash on the warm dark background (H.264) |
| `LogoRevealTransparent` | `out/JuveNILE_LogoReveal_Alpha.webm`   | Same animation with alpha (VP8), to overlay on your own background |

Copies of both renders live in `Assets/Videos/Splash/`. In Unity, play them with a `VideoPlayer`
(Render Mode: Camera Far Plane / Render Texture). For the WebM, enable **Keep Alpha** in the
clip's import settings.

## Commands

```bash
npm install
npm run studio        # live preview / scrub in the browser
npm run render        # MP4
npm run render:alpha  # transparent WebM
npm run still         # poster frame PNG (finished logo)
npm run typecheck
```

Render at 4K with `--scale=2`, or change the fps in `src/Root.tsx`. All timings are in seconds
in `src/timeline.ts`, so the animation keeps its pace at any frame rate.

## How the logo is built

`src/logoPaths.ts` is generated by `npm run build:paths` from `assets/juvenile-logo-source.png`:

- **Wordmark**: real glyph outlines from **Quicksand Medium (500)**, the logo font
  (`@fontsource/quicksand`). The letters in the logo are condensed to ~94% of stock Quicksand
  width, so the script measures one shared x/y scale from the image and centres each glyph on
  its letter. The result matches the source at 95–99.8% pixel overlap per letter.
- **Beetle icon**: not a font glyph, so it is traced with potrace and split into its outline and
  its holes (d-pad, buttons). Draw the traced icon with `fill-rule="evenodd"`.

The beetle is one connected shape (the legs touch the body), so `src/Beetle.tsx` splits it into
the two body halves and six legs with clip paths and masks rather than separate paths.
